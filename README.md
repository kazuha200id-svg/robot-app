# Robot Companion Controller App

Aplikasi Android resmi untuk **Robot Desk**.

## ✨ Fitur Utama
- **Tema Desain**: 100% Monokrom **Biru Neon (Electric Cyan `#00F0FF`)**
- **Ikon**: Vektor Garis Kustom Bergaya HUD Futuristik (Bebas emoji warna-warni)
- **Navigasi**: Sistem **Multi-Halaman Penuh** (bukan di-scroll, ganti layar seketika)
- **Koneksi**: Murni **Bluetooth Low Energy (BLE)** direct chip-to-chip tanpa server, tanpa router, tanpa Wi-Fi!

## 📱 Halaman Aplikasi
1. **Status & Telemetri**: RAM Monitor (desimal akurat), Uptime, Mode Aktif, Tidur / Bangun.
2. **Studio Wajah (13 Wajah OLED)**: Ganti instan seluruh ekspresi robot + Colek/Elus/Goyang.
3. **Teks Berjalan**: Kirim running text seketika ke layar OLED robot.
4. **Jam & Alarm**: Sinkronisasi waktu 1-klik dari jam HP, pengaturan alarm dan uji buzzer.
5. **Game Center & Gamepad**: Katalog 10 game arcade + Gamepad action jump virtual.
6. **Kontrol Sistem**: Tes buzzer, tes getar haptic, dan restart perangkat.

## 🚀 Build Otomatis via GitHub Actions
Setiap push ke repositori ini akan memicu server GitHub untuk meng-compile file **`RobotCompanion.apk`** secara otomatis dan menyediakannya di tab **Releases** / **Actions Artifacts**.
